_Advocacy for oversight and NoAI tags could limit new competitors._

Regulation can create a moat. Sam Altman has been on tour with policymakers advocating for more oversight and control. Additionally, OpenAI now allows blocking their scraping mechanism with a NoAI tag. Both efforts would create a moat in two ways: First, regulators would allow OpenAI as a tool but be more restrictive to newcomers. Second, newcomers could no longer scrape data with a NoAI tag. This is one of five strategies in OpenAI's playbook to secure its investments.
