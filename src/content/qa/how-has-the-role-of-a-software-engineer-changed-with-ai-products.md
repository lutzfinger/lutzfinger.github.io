_From writing code to spec to designing probabilistic loops._

A traditional software engineer writes code to spec. The system does what it was told, and reliability comes from precise requirements and clean implementation. An engineer building AI products today works in a fundamentally different environment. The system does not do what it is told. LLMs write code and produce probabilistic outputs. The job is no longer writing features. It is designing loops: how does the agent decide when to stop? What happens when a tool call returns an invalid schema? How do you catch a hallucination midway through a workflow? These are not software questions. They are system judgment questions.
