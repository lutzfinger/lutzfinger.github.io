_AI misidentified world leaders' genders, sparking calls for accountability._

Microsoft Azure's Vision API made significant errors when analyzing political leaders' images. It identified Angela Merkel as a boy and classified Joe Biden as both a man and a woman. After online mockery about Merkel's misjudged gender, Microsoft changed their algorithm. However, this update happened without transparency about when and how the algorithm changed, illustrating a broader problem with AI systems that can be wrong and biased but operate without public accountability.
