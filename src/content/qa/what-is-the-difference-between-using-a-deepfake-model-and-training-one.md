_Using deepfakes is simple, but building the underlying models is not._

There is a big difference between using a model and training a model. Today, you can create a deepfake for free in less than 30 seconds using sites like MyHeritage, D-ID, or many free deepfake applications without any programming skills. However, before we reach that self-serve tool point, we must first build a model that enables it. Underlying all deepfake tools are AI models based on neural networks. These models need a lot of training data, and creating them is not simple at all.
