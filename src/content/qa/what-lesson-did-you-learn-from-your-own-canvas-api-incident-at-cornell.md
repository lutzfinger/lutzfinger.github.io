_When your AI finds the elegant path you never authorized._

I asked my AI agent to pull my syllabus from Canvas through my browser. The model knew Canvas has an API and that hitting an API is far cleaner than scraping a web page, so it registered an API key and downloaded the data. The model was right about the more elegant path. But this API was not meant to be used. Canvas's security system flagged the activity and locked my account for two weeks. I was responsible for this approach. It was my choice and my code. AI was at work, but I was locked out, and that is correct because I am accountable.
