_Ownership and unique value creation are both required for protection._

A data moat is created when the data you have creates value no one else can easily create, and you own the data. Google has a data moat because they know how to link a search query to a click, while ChatGPT does not know whether the user found an answer helpful. I failed with my own company Fisheye Analytics because our scraped data was not protected. If I can scrape it, anyone can scrape it. Bloomberg launched a massive financial LLM only they could have trained. In this new world, data access is key.
