_AI generates options; humans decide which path to take._

Those workflows are neither automatic and far from autonomous. Thus it needs new talent. Talent that can write code together with an LLM. Talent that can understand the new product design. While we see those layoffs I stay to my view that we will need humans. Humans that know how to work with AI. Humans that decide on options generated by an AI. This is the same argument I made for creative teams, we need them to work with AI tools but AI cannot replace human judgment.
