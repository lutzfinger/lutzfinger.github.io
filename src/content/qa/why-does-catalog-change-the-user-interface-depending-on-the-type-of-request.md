_Dynamic interfaces that adapt to what you actually need to see._

We maintain about twenty to twenty-five abstract views, not thousands of deterministic flows like traditional enterprise tools. If it's a search, we render search results. If you ask for a summary, we render a summary view. If you ask for revenue from Q2 2023, we render a graph. The LLM dynamically adapts the interface to the use case. This is one level of abstraction higher than traditional UIs, which build very bespoke workflow-level interfaces. Ninety percent of use cases fall within the first five views.

— [Large Language Models: one interface to rule them all?](https://www.lutzfinger.com/transcript/2023-08-15-large-language-models-one-interface-to-rule-them-all/) · _The Edge_
